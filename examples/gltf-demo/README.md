# glTF village

A small village built from Grodot's own low-poly kit in `assets/models/`
(generated by `tools/gen_gltf_kit.py`, CC0). The kit deliberately uses every
format the importer reads:

| File | Format |
| --- | --- |
| `house.glb`, `crate.glb` | binary glTF with embedded PNG textures |
| `pine_tree.glb`, `round_tree.glb`, `rocks.glb` | binary glTF, node hierarchies with TRS |
| `fence.glb` | includes a line primitive (the wire) |
| `lamp_post.gltf` + `lamp_post.bin` | JSON glTF with an external buffer |
| `bush.gltf` | JSON glTF with an embedded base64 buffer |

In the editor, drag a model from the Assets tab into the viewport to place it,
or select an entity and press **Use as mesh**.

```sh
grodot open examples/gltf-demo
```
