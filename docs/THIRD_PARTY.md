# Third-party material

Grodot has no third-party code dependencies.

## Inter (font data)

`crates/grodot-render/assets/fonts.bin` contains glyph bitmaps rasterized from
the Inter typeface by `tools/gen_font.py`.

Inter is Copyright (c) 2016 The Inter Project Authors and is licensed under
the SIL Open Font License, Version 1.1 (https://openfontlicense.org).

## Sounds

The sample game's sounds in `examples/orb-garden/assets/audio` are synthesized
by `tools/gen_sounds.py` and are released under the project's MIT license.
